# HEL3054 - Medical Data Initial Exploration

Initial data exploration for synthetic medical data.

During this class we explore and describe three related datasets. The data includes a cohort of individuals, Ischaemic Heart Disease (IHD) diagnoses and link to the death registry. The data is fully synthetic and is derived from (<https://github.com/theresenoest/HEL3054-MedicalData>). Our main aim for the day will be to practice manipulation, exploratory data analysis, visualization and merging datasets.

We will follow the `.qmd` files according to their number.
