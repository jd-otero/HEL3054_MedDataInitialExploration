# HEL3054_MedDataInitialExploration
Initial data exploration for synthetic medical data

During this class we explore and describe three related datasets. the data includes a cohort of individuals, Ischaemic Heart Disease (IHD) diagnoses and link to the death registry. The data is derived from (https://github.com/theresenoest/HEL3054-MedicalData). Our main aim for the day will be to practice exploratory data analysis.
